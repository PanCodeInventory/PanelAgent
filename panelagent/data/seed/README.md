# Seed data

These files are packaged snapshots of the repository's authoritative `config/`
files. Regenerate them whenever the corresponding configuration changes.

The CytoFLEX mapping names `AmCyan`, `V450`, `V500`, and
`Fixable Viability Stain 780` have channels but no matching spectrum. They are
resolved with channel and brightness data where available. Brightness-only dyes
without spectra are `BUV395`, `BUV496`, `BUV563`, `BUV661`, `BUV737`, and
`BUV805`.
